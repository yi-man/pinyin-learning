# 拼音学习 MVP 规格文档

## 1. 概述与目标

本项目旨在构建一个简洁高效的拼音学习工具，为汉语学习者提供完整的拼音字母表展示和即点即读的发音功能。用户可以通过直观的界面浏览所有声母、韵母，并点击任意拼音快速听到标准发音。

## 2. 设计愿景

采用「教科书美学」设计方向——模拟传统语文教材的清新感和专业感，结合现代交互体验。整体风格偏向柔和、学术、富有书卷气息。

### 视觉方向
- **主色调**: 米白纸张色背景 (#FDFBF7) + 墨绿色强调 (#2D5A4A)
- **字体**: 使用衬线体标题增加学术气息，无衬线体正文保证可读性
- **布局**: 清晰的分块展示，每个拼音类别独立成区
- **动效**: 轻柔的点击反馈，播放时优雅的波纹扩散动画

## 3. 功能需求

### 3.1 拼音列表展示

系统展示完整的汉语拼音字母表，按类别分组：

#### 声母表 (23个)
| 类别 | 字母 |
|------|------|
| 爆破音 | b, p, m, f |
| 舌尖音 | d, t, n, l |
| 舌根音 | g, k, h |
| 舌面前音 | j, q, x |
| 舌尖后音 | zh, ch, sh, r |
| 舌尖前音 | z, c, s |
| 半元音 | y, w |

#### 韵母表
| 类别 | 字母 |
|------|------|
| 单韵母 | a, o, e, i, u, ü, ê |
| 复韵母 | ai, ei, ui, ao, ou, iu, ie, üe, er |
| 鼻韵母 | an, en, in, un, ün, ang, eng, ing, ong |

#### 展示要求
- 按类别分组展示，每组有清晰的标题
- 每个拼音显示为大号可点击卡片
- 视觉上区分声母和韵母两大类

### 3.2 拼音点读发音

使用 Web Speech API (SpeechSynthesis) 实现拼音发音：

- 点击任意拼音卡片触发发音
- 使用中文语音 (zh-CN)
- 音调设置为正确的中文发音

### 3.3 视觉反馈

- **播放中状态**: 当前播放的拼音卡片显示波纹扩散动画
- **悬停效果**: 卡片悬停时轻微上浮并加深阴影
- **点击效果**: 点击瞬间卡片轻微缩小再恢复

## 4. 技术方案

### 技术栈
- **框架**: Next.js 16 (App Router)
- **样式**: Tailwind CSS v4
- **音频**: Web Speech API (原生浏览器API)
- **测试**: Playwright

### 文件结构
```
src/
├── app/
│   ├── page.tsx          # 拼音列表首页
│   ├── layout.tsx        # 应用布局
│   └── globals.css       # 全局样式
├── components/
│   └── pinyin/
│       ├── PinyinCard.tsx       # 单个拼音卡片组件
│       ├── PinyinSection.tsx    # 拼音分类区块组件
│       └── PinyinList.tsx       # 拼音列表主组件
├── data/
│   └── pinyin.ts         # 拼音数据定义
└── hooks/
    └── usePinyinAudio.ts # 拼音发音 Hook
```

### 响应式设计
- **桌面端 (≥768px)**: 网格布局，每行4-6个卡片
- **移动端 (<768px)**: 每行3个卡片，触摸友好的尺寸

- [ ] 播放时有视觉反馈动画

- [ ] 卡片悬停和点击有动效反馈

## 6. 边界情况处理

- **浏览器不支持 Speech API**: 显示友好提示"您的浏览器不支持语音功能"
- **语音播放中再次点击**: 停止当前播放，开始新的播放
- **网络问题**: Web Speech API 为本地功能，无需网络
